# رنک ترکر (Rank Tracker)

ابزار بررسی رتبه سایت در گوگل، برای هر پروژه، هر کلمه کلیدی و **هر نقطه جغرافیایی** (مختصات GPS یا نام شهر)، با موبایل و دسکتاپ.

🔗 **نسخه آنلاین:** https://shahab-1997.github.io/rank-tracker/

## ویژگی‌ها

- چند پروژه، هر کدام با دامنه، کلمات کلیدی، نقطه‌های جغرافیایی و دستگاه‌های خودش
- انتخاب نقطه از روی نقشه، با مختصات، یا با نام canonical گوگل
- تکرار هر جستجو و گزارش **میانه** + **نوسان** رتبه (رتبه بین دیتاسنترهای گوگل ثابت نیست)
- دو نوع رتبه: **ارگانیک** و **مطلق** (با احتساب Featured Snippet، Local Pack و …)
- مقایسه با بررسی قبلی (▲▼) و نمودار تاریخچه
- اتصال به **Google Search Console** برای دیدن رتبه واقعی کاربران کنار نتایج
- خروجی CSV و فایل پشتیبان

## حریم خصوصی

نسخه آنلاین کاملاً در مرورگر اجرا می‌شود. پروژه‌ها، تاریخچه و کلیدهای API فقط در مرورگر هر کاربر (localStorage) ذخیره می‌شوند و مستقیم به DataForSEO / گوگل فرستاده می‌شوند. هیچ سرور واسطی وجود ندارد.

## منبع داده

- **DataForSEO** — جستجوی گوگل از مختصات دقیق. هر کاربر کلید خودش را وارد می‌کند.
- **Google Search Console API** — میانگین رتبه واقعی (به تفکیک کشور و دستگاه).
- **حالت نمایشی** — داده ساختگی برای آشنایی با ابزار.

## ساختار مخزن

| پوشه | توضیح |
|---|---|
| `docs/` | نسخه آنلاین (GitHub Pages) |
| `local-app/` | نسخه پایتون برای اجرا روی کامپیوتر خودتان (`start-windows.bat`) — از SerpApi هم پشتیبانی می‌کند |

## راه‌اندازی Search Console در نسخه آنلاین (برای مالک سایت)

1. در [Google Cloud Console](https://console.cloud.google.com/) پروژه بسازید و **Google Search Console API** را فعال کنید.
2. در *APIs & Services → OAuth consent screen* صفحه رضایت را بسازید (نوع External).
3. در *Credentials → Create credentials → OAuth client ID* نوع **Web application** را انتخاب کنید و در *Authorized JavaScript origins* این را اضافه کنید: `https://shahab-1997.github.io`
4. Client ID ساخته‌شده را در فایل `docs/config.js` قرار دهید.

> تا وقتی برنامه OAuth توسط گوگل verify نشده، فقط کاربرانی که در بخش *Test users* اضافه کرده‌اید می‌توانند وارد شوند. هر کاربر هم می‌تواند Client ID خودش را در تنظیمات سایت وارد کند.
