سرویس جستجو

کلیدها فقط در مرورگر خود شما ذخیره می‌شوند و مستقیم به DataForSEO فرستاده می‌شوند؛ هیچ سرور واسطی در کار نیست.

Google Search Console

برای دریافت رتبه واقعی از Search Console، روی دکمه «دریافت از Search Console» در صفحه پروژه بزنید و با حساب گوگلی که به سایت دسترسی دارد وارد شوید.

پشتیبان‌گیری

همه پروژه‌ها و تاریخچه فقط در همین مرورگر ذخیره شده‌اند. برای انتقال به کامپیوتر دیگر یا جلوگیری از پاک شدن، فایل پشتیبان بگیرید.

این ابزار چطور رتبه را می‌سنجد؟

  • هر جستجو از نقطه دقیق جغرافیایی (مختصات GPS یا نام شهر) و با دستگاه مشخص (موبایل/دسکتاپ) انجام می‌شود.
  • هر جستجو چند بار تکرار می‌شود و میانه گزارش می‌شود؛ ستون «نوسان» نشان می‌دهد رتبه بین دیتاسنترهای گوگل چقدر بالا و پایین می‌رود.
  • رتبه فقط بین نتایج ارگانیک است. رتبه مطلق المان‌هایی مثل Featured Snippet و Local Pack را هم می‌شمارد. اختلاف ابزارها اغلب از همین‌جاست.
  • ستون Search Console میانگین رتبه واقعی شما جلوی کاربران واقعی در ۳۰ روز اخیر است (داده خود گوگل). اگر با عدد بررسی فاصله زیادی دارد، به عدد Search Console اعتماد کنید.
  • رتبه‌ای که خودتان در مرورگرتان می‌بینید شخصی‌سازی‌شده است و معیار درستی برای مقایسه نیست.

شروع کار

  1. در dataforseo.com ثبت‌نام کنید و از داشبورد، API Login و API Password را بردارید.
  2. در تب «تنظیمات» آن‌ها را وارد کنید و «تست اتصال» را بزنید.
  3. یک پروژه بسازید: دامنه، کلمات کلیدی و نقطه‌های جغرافیایی.
  4. «بررسی رتبه‌ها» را بزنید. هزینه هر بررسی = کلمات × نقطه‌ها × دستگاه‌ها × تعداد تکرار جستجو.
  5. اختیاری: «دریافت از Search Console» را بزنید تا رتبه واقعی هم کنار نتایج بیاید.
